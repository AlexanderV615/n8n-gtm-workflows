# Security Policy

## Reporting a vulnerability

Report privately via [GitHub Security Advisories](https://github.com/AlexanderV615/n8n-gtm-workflows/security/advisories/new).
Do not open a public issue for security problems.

Include: affected workflow(s), description + impact, repro steps if you have them.

## Supported versions

Only `main` is supported; fixes are not backported.
